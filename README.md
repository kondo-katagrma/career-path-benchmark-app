# キャリアパス アンケート傾向ベンチマーク（ブラウザツール）

現状把握アンケート（キャリアパス策定支援フォーマット）を読み込むと、**貴法人 vs これまでの全法人の傾向**（量的＝雇用・勤続・満足など／質的＝専門志向・役割明確化・育成 など）を自動で表にします。

## 使い方（誰でも）
1. `index.html` をブラウザで開く（**サーバー不要・Claude不要**。ダブルクリックでOK）。
2. 取り込み方は2通り：
   - **URLを貼る**（推奨）：アンケート（スプレッドシート）のURLを貼り「URLから取得」。初回のみ管理者が Apps Script を設置します（→ `DEPLOY.md`）。**集計はGoogle側で行い、集計値のみ**がブラウザに届きます（PII安全）。
   - **ファイルを選ぶ**：`.xlsx` / `.csv` を選択（設置不要・完全ローカル）。
3. 「貴法人 vs 全法人」の表が出る。
- **回答タブは自動判別**（役職・勤続などの列を持つシートを検出。タブ名の統一は不要）。
- ファイル選択は**ブラウザ内だけ**で処理。URL取得は**Google側で集計し数値のみ返す**ため、いずれも**氏名等のPIIは外に出ません**（画面にも出しません）。

## ベースライン（全法人の集計値）の更新 ＝ 事例が増えたら母数を増やす
ベースラインは `index.html` 内の `const BASE = {...}` に埋め込んでいます（＝単一ファイルで動く）。更新手順：
1. 各法人のフォーマットを **XLSX** で作業フォルダに保存（Google Driveから `spreadsheetml.sheet` でダウンロード→base64復元）。
2. `parse_xlsx_responses.ps1`（career-path Skill同梱）で回答シートをCSV化。
3. `gen_baseline_json.ps1 -RespDir <csvフォルダ> -OutJson baseline.json` で最新の集計JSONを生成。
4. `baseline.json` の中身を `index.html` の `const BASE = { ... };` に貼り替える。
- 進行中の法人・実回答n<5・テンプレート（大元/商談用/保存用）は自動除外。
- `.ps1` は日本語を含むため UTF-8 BOM で保存して実行。

## GitHub Pages で共有する場合
このフォルダをリポジトリにして Pages を有効化すれば、URLで配布できます（`index.html` は単一ファイルで完結するため `baseline.json` は無くても動作。`baseline.json`・`*.ps1` は更新用に同梱）。

## 全体の流れ（アプリ内に表示）
アプリ内の「全体の流れ」に、第3回準備の全工程と担当を表示します。
- アンケートの集計・傾向の可視化 → **このツール**（誰でも・ローカル完結）
- 方針メモ抽出／自由記述からの課題の読み解き／レポート文章の作成／ヒアリング設計 → **Claude（career-path プラグイン）**。判断・文章化が必要なため静的アプリでは再現できない工程。

## Claudeで仕上げる（下書きプロンプト生成）
ファイルを読み込むと「Claudeで仕上げる」に、**集計結果を反映した下書きプロンプト**が生成されます（トーン規則入り）。コピーして career-path プラグイン／Claude に貼れば、レポートの傾向節が作れます。**プロンプトには集計値のみ**を含み、氏名等の個票は入りません（PII安全）。
